source-defined 문항과 보기를 바꾸지 않고 한 문항씩 대화형으로 표시합니다.

건강검진 실시기준 별지 제1호 서식을 그대로 질문하며, 만 66·70·80세에는 별지 제2호 추가 문진표도 이어서 질문합니다. 검진 예정일은 공식 문항 선택에 필요하지 않아 묻지 않습니다.

문항·보기·순서는 공식 원문과 대조했지만 FHIR 구조화본은 미검토 draft입니다. 공식 수검자격 조회나 검진표 제출에는 사용할 수 없습니다.

이미지를 선택하면 여기에서 확인합니다.

OCR 및 문항 구조화 adapter는 아직 구현되지 않았습니다. 업로드·미리보기만 지원합니다.

증상만 입력하는 곳이 아닙니다. 예약 진료의 이유, 재진, 검사결과 상담, 복용약 검토, 퇴원 후 상태 등 의료진에게 미리 전달할 내용을 자유롭게 시작할 수 있습니다.

Local LLM은 분리된 내부 환경에서 처리되며 외부 상용 LLM으로 전송하지 않습니다.

데모의 Local LLM 대신 개인 상용 LLM API 계정을 사용하려면 위 기관·개발자용 인증 API에 먼저 연결하세요. 상용 LLM은 관리자가 허용한 provider와 model이 함께 지정되고 서버에 API credential이 안전하게 구성된 경우에만 표시됩니다. Key 하나만으로 제공자·모델을 자동 판별하지 않으며 개인 계정 비밀번호나 상용 LLM key는 이 화면에서 수집하지 않습니다.
