# Chatbot test–CIAI 비정형 대화 비교

## 범위

- 실행일: 2026-08-20
- 입력은 모두 합성 사례이며 실제 환자정보를 포함하지 않는다.
- Chatbot test와 공개 CIAI 데모에 같은 목적·상황을 입력해 라우팅, 한 질문 원칙, 보기, Knowledge 출처, red flag, 자발정보 재사용을 비교했다.
- 질문 문장의 작은 표현 차이보다 동일한 Knowledge 범위와 workflow 계약을 우선 판정했다.

## 발견·수정한 결함

1. Chatbot test에서 익명 통계 Action이 잘못된 버전 형식으로 실패하거나 지연되면 통계 안내만 표시하고 첫 질문으로 진행하지 않는 사례가 재현됐다. `gpt_config_version`을 `1.50.0`으로 고정하고, Action 성공 여부와 무관하게 같은 assistant 응답에서 첫 질문까지 계속하도록 공통 지침을 강화했다.
2. CIAI 건강검진 추천에서 한 답변에 나이와 성별을 모두 제공해도 성별을 다시 묻는 결함이 있었다. 같은 turn에서 추출된 기존 Fact의 질문을 건너뛰도록 Runtime을 수정했다.
3. 건강검진 추천의 공통 지침에 `만 나이 → 성별 관련 맥락 → 걱정·이상 소견·증상·가족력` 순서를 명시했다.

## 회귀 기준

- 세 범주는 서로 다른 목적을 유지한다: 진료 전 문진은 clinician handoff, 일반 건강상담은 질문자 정보 제공과 triage, 건강검진 추천은 국가검진 외 패키지 비교다.
- 한 응답에는 answer-bearing 질문 하나만 표시한다.
- 동적 질문은 실제 compiled Knowledge Question과 출처 ID를 사용한다.
- 이미 명확하게 제공된 Fact는 다시 묻지 않는다.
- 일반 건강상담의 명백한 red flag는 LLM 호출보다 먼저 안전 안내로 전환한다.
- 건강검진 추천은 선행정보가 없을 때 나이와 성별을 먼저 각각 확인한다.
